# Крошка

Небольшой многостраничный сайт кофейни-пекарни на обычных HTML, CSS и JavaScript. Фреймворки, сервер и платёжные интеграции не используются.

## Страницы

- `index.html` — главная;
- `menu.html` — каталог, поиск, категории, сортировка и корзина;
- `favorites.html` — товары, отмеченные сердцем;
- `about.html` — о кофейне;
- `visit.html` — адрес, часы работы и ссылка на Google Maps;
- `order.html` — оформление самовывоза.

Каталог, комбо и простые пары-рекомендации находятся в `menu-data.js`. Общая логика корзины, темы, избранного, недавних просмотров и навигации — в `js_main1.js`; сценарий заказа — в `order.js`.

## Запуск

Для быстрой проверки можно открыть `index.html` в браузере. Для локального веб-сервера подойдёт любой статический сервер; сборка не требуется. GitHub Pages публикует сайт из корня репозитория.

## Корзина и демо-оформление

Корзина, тема и последний заказ хранятся локально в браузере посетителя. Демо-оформление показывает номер и итог, сохраняет локальную историю и позволяет скопировать текст заказа. Заказ не отправляется владельцу или кофейне, оплата не выполняется, сетевых интеграций в checkout нет.

Избранное и недавно просмотренные товары также сохраняются только в браузере этого устройства. Наборы рассчитываются по сумме обычных цен товаров — скидки не применяются.

## Установка и работа офлайн

Сайт включает `manifest.json`, SVG/PNG-иконки и лёгкий Service Worker для основных страниц, скриптов и локальных изображений. На поддерживаемых браузерах сайт можно установить из меню браузера. Установка доступна только на HTTPS (GitHub Pages подходит) и после первого посещения, когда основные страницы были закэшированы. Корзина и избранное продолжат храниться локально; оформление заказа остаётся демо и не отправляется.

Service Worker обновляет локальные файлы при доступе к сети и использует кэш, когда сети нет. Неизвестные маршруты офлайн показывают локальную страницу `404.html`. При изменении набора предварительно кэшируемых страниц или ресурсов увеличивайте `CACHE_NAME` в `sw.js`, чтобы установленные копии получили новую версию оболочки.
